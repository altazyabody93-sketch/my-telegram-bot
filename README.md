# 🛍️ Telegram Store Bot

بوت تيليجرام لمتجر إلكتروني متكامل مع:
- ✅ نظام منتجات (بيع تلقائي/يدوي)
- ✅ نظام شحن رصيد بالنجوم
- ✅ نظام إحالات (شارك واربح)
- ✅ لوحة تحكم كاملة للأدمن
- ✅ إحصائيات متقدمة

## 🚀 التشغيل على Render

1. ارفع الملفات على GitHub
2. أنشئ Web Service على Render
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. أضف Environment Variable: `BOT_TOKEN`
